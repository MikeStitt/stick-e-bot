End a run plan with a detailed section that unrolls its loops: one line per tab, per part and per
ring item, each marked **Done** only once it has been performed and passed. Write it before the
work starts, not after.

**Why:** a plan that says "then Ring 2 on each tab" hides how many checks that is, and a ring item
nobody wrote down is a ring item nobody misses. draft9p5's `ball and socket` was reported as
through Ring 2 while two of its items had never been run — the brief's own acceptance checks, which
name the two parts `Ball stud` and `Socket body`, and the section held beside the brief's sheet.
The tab's shape, parameters and renders all agreed, so nothing failed; the items were simply not on
any list. Mike asked for the unrolled list after that.

**How to apply:** unroll every loop the plan describes — each tab, each part inside it, each ring,
each numbered acceptance check the brief carries. Mark a line Done when it has passed, not when it
has been attempted, and leave it unmarked with a reason when it is skipped. The list is the
report: [[no-invented-gates]] still applies, so a line is closed by naming the evidence rather than
by asserting it. Related: [[read-think-plan-do]], [[fix-the-model-retake-the-frames]].
