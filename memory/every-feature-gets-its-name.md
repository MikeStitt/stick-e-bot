A build is not finished at `Sketch 1`, `Extrude 4`, `Revolve 1`. **Type the name into the feature
dialog's title before filling the dialog in** — this works for every feature type — the way a
function gets its name before its body. Renaming afterwards cannot repair a frame already taken:
the tree row and the dialog header are both in the picture, so a name set last is wrong in every
screenshot of that step.

Capture at the same rate. Someone new to Onshape needs to see **what to click and what to
fill out**: the dialog with its fields filled, before the tick, not just the finished
solid. Run 6's hinge produced 160 shots and still could not show a reader which button
made the feature, because the shots were of geometry.

**Why:** the run 6 instruction spike could not be used — not enough visual material to
teach a beginner, and a tree full of default names.

**How to apply:** name first, fill second, shoot, then tick. A dialog titled `foot outline` also
labels its own screenshot, so the picture says which step it belongs to without a caption. See
[[write-for-students-who-will-succeed]].
