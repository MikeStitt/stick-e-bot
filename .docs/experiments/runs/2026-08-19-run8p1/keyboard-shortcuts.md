# Onshape's keyboard shortcuts, read out of Onshape

Read from the **Keyboard shortcuts** panel ( *shift+/* ) on 2026-08-19, in
`run8-ball-and-socket` on port 9223. Not recalled — every row below was on the screen.

The panel is per tab. A tool absent from its tab has no default shortcut: **Boolean**,
**Circular pattern** and **Linear pattern** are all absent, so no step may offer a key for them.

This is a transcript, not a rule. The rule is in
[`../../../../.parts/onshape.md`](../../../../.parts/onshape.md), _Writing steps_: name the mouse
action, put the key after it in parentheses, lower case.
