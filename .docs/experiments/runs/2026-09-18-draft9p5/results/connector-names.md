# Phase A — the ten connector names

The ruling, settled 2026-09-11: a connector is named for the joint it is, without the word
*connector*, and one that marks a placement takes `mate for …`. The names below are what draft9p5
builds; the old name is here so a record read from a parent can be matched to it.

Every old name was checked against the parents' records on 2026-09-18 and each is there, spelled as
the plan spells it. The eight Part Studios hold 23 `mateConnector` features in all: `body` 8,
`hinge` 3, `head` 2, `ball and socket` 2, `u limb` 3, `l limb` 3, `foot` 1, `gripper` 1.

## `body`, eight of them

| Build it as | Was | What it is |
| ----------- | --- | ---------- |
| `neck` | `neck connector` | the joint the head sits on |
| `left shoulder` | `left shoulder connector` | the joint an arm hangs from |
| `right shoulder` | `r shoulder connector` | the same, other side |
| `left hip` | `l hip connector` | the joint a leg hangs from |
| `right hip` | `r hip connector` | the same, other side |
| `mate for shoulder stud` | `connector on torso shoulder` | a placement, not a joint |
| `mate for hip stud` | `hip connector on torso` | a placement |
| `mate for neck stud` | `neck connector on torso` | a placement |

The two sketches under them are `hip stud location` and `neck stud location`, from
`hip connector location` and `neck connector location`.

## `hinge`, two of them

| Build it as | Was |
| ----------- | --- |
| `fork to robot` | `fork to robot connector` |
| `blade to robot` | `blade to robot connector` |

`hinge`'s third, `axis for circular patterns`, is not a joint end and does not carry the word, so it
keeps its name.

## Noticed, and not changed

`ball and socket` names its two `stud connect to robot` and `socket connect to robot`. They carry
*connect* rather than *connector*, so the plan's count of ten does not include them and its rename
table does not name them. Everything not in the table keeps the name its parent gave it, so
draft9p5 builds them as they are. This is written down because the next person to read the ruling
will wonder.
